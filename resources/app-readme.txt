提瓦特旋律 —— 使用与卸载说明
==============================

【你的数据存在哪？】
  数据（曲库、歌单、设置、自定义源、下载的歌、缓存）**都在软件目录里，跟 EXE 同级**。
  免安装版与安装版都一样，整个目录自包含 —— 可以整体复制、搬移到别的电脑继续用。

      data/      曲库数据库（歌曲、歌单、收藏、播放历史）
      music/     扫描入库的音乐副本；在线下载的歌也存这里
      cache/     在线播放的音频与歌词缓存（可随时清空）
      .appdata/  设置、桌面歌词位置、播放进度等
      sources/   你导入的自定义源脚本

  「设置 → 关于与更新」里会显示当前的数据目录，并可一键打开。

  ⚠️ **重要：升级会保留数据，但「卸载」会删掉数据。**
     · 升级（装新版本覆盖）→ data / music / sources / cache / .appdata 原样保留
     · 卸载（从「应用和功能」里卸载）→ 连同数据一起删除，无法恢复
     所以：**卸载前请先备份**（把上面几个文件夹复制到别处），
     或者改用免安装版（删文件夹即卸载，数据想留就留着）。

【免安装版（便携版）】
  如果你看到的是解压出来的文件夹：直接双击 TeyvatMelody.exe 运行，无需安装。

  · 数据都在本目录下，整个文件夹可以随意搬移（U 盘、换电脑都行）。
  · 卸载 = 直接删除整个文件夹。
    （免安装版没有卸载程序是正常的，它本来就不往系统里写东西。
      如果想让系统里不留痕迹，删除前先关掉正在运行的程序。）

【安装版】
  如果你是用 TeyvatMelody-Setup-<版本>.exe 安装的：

  · 安装位置：%LOCALAPPDATA%\Programs\TeyvatMelody
    （在资源管理器地址栏粘贴这一行即可打开）
  · 数据位置：安装目录里（与 TeyvatMelody.exe 同级）
  · 卸载方式（二选一）：
      1. 打开安装目录，运行 Uninstall TeyvatMelody.exe
      2. 「设置 → 应用 → 已安装的应用」里搜索「提瓦特旋律」，点击卸载
  · **卸载会同时删除数据**；想保留请先备份，或改用免安装版。

【在线歌曲与下载】
  · 在线歌曲可以像本地歌一样「收藏」和「加入歌单」。
  · 右键在线歌曲可以选择音质，或「下载到本地」——下载后会存进 music/ 目录并自动
    进入音乐库，从此离线可播，封面、歌词、标签都会一并写入。
  · 在线播放的音频与歌词会缓存在 cache/ 下，重播更快；缓存上限与清空在
    「设置 → 在线播放缓存」里。

【想换一种分发方式？】
  两种格式的数据是通用的：把 data / music / .appdata / sources 复制到另一份的
  软件目录下即可无缝接续（音乐库、歌单、设置、自定义源都会保留）。
