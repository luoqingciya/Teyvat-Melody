# Teyvat Melody（提瓦特旋律）

基于 **Electron + Python 3.12 (Flask) + Vue 3 (Vite)** 的原神主题风格本地音乐播放器桌面应用。

> 应用图标、macOS entitlements 等打包资源存放于此目录。

```
resources/
├── TeyvatMelody.ico    # Windows 应用图标（多尺寸，已接入 build.spec）
├── TeyvatMelody.jpg    # 高分辨率源图（原神主题：地脉 + 七色元素 + 八音盒）
├── icon.icns           # macOS 应用图标（待补充）
└── entitlements.plist  # macOS 打包签名配置（待补充）
```
