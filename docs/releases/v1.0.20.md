# v1.0.20

把**在线播放缓存**的设置拆细了：可以按类别查看和清理。

## 现在的样子

**资源缓存管理**
- 音频：N 份 · X MB（含下载中 Y MB）
- ［清理资源缓存］

**其他缓存管理**
- 歌词：N 份 · X KB
- ［清理歌词缓存］

**软件已使用缓存大小：X MB**　［清空全部缓存］

音频和歌词分开统计、分开清理。之前只有一个合计数字和一个「清空」按钮 ——
想重取歌词就得把几十 MB 的音频一起扔掉，不太合理。

## 说明：有两条我们没有

你给的那张图里还有「**换源歌曲信息**」和「**歌曲 URL**」两类缓存 ——
这两个是洛雪特有的，**我们这边不存在**，原因在架构不同：

- 洛雪缓存的是**解析结果**（歌曲信息和播放地址），所以地址过期后要重新解析；
- 我们直接缓存**音频文件本身**（就是这里的「资源缓存」）——
  重播、拖动进度条都直接读本地文件，比缓存地址更彻底，也不需要担心地址过期。

所以对应关系是：

| 洛雪 | 本软件 |
|---|---|
| 资源缓存（音频） | 资源缓存 → 音频 |
| 歌曲 URL / 换源歌曲信息 | **不需要**（我们缓存的是音频本身） |
| 歌词 | 其他缓存 → 歌词 |

封面走的是浏览器缓存，不单独占磁盘目录，所以也没有单列。

## 升级提示

- **数据不会丢**：安装版升级时曲库、歌单、收藏、缓存、代理设置都会保留。
- **卸载会连同数据一起删除**，卸载前请先备份 `data/` `music/` `cache/` `sources/` 这几个目录。
- 免安装版（zip）直接解压覆盖即可。

> 如果你还在 v1.0.17 之前，请**手动下载安装包**升级一次 ——
> 那些版本的「下载并安装」是坏的，修不了自己。
