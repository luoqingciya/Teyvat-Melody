# 提瓦特旋律 v1.0.8

## 在线搜索更好用了

### 搜索结果不再「切走就没了」

以前从「在线搜索」切到别的页面再回来，搜过的关键词和结果列表就全空了，得重新搜一遍。
原因是**页面切换时搜索组件会被销毁**，它内部保存的状态也跟着没了。

现在把搜索现场移到了更持久的地方，于是：

- 切到「我的音乐」「设置」等任何页面再回来，**关键词、结果列表、滚动位置原样都在**；
- 连**关闭应用重新打开**，上次的搜索结果也还在（不用重新搜）；
- 之前勾选的搜索来源（平台）同样会被记住。

### 新增翻页 —— 可以翻到更多结果了

以前一次只能看到前 30 条，且**没有任何翻页入口**，所以确实会让人疑惑
「是只能显示这么多，还是只能搜到这么多」。

现在结果列表底部有分页器（上一页 / 下一页 + 当前页码），顶部还会显示
**「共 N 条 · 第 N 页」**；翻到上限时会明确标出 **「已到上限」**，
而不是静默地变少 —— 想找更多可以换个更具体的关键词。

> 上限是 **300 条**（10 页 × 30 条，跨页自动去重）。
> 各平台单页能给的条数由平台自己决定，所以有时某平台先翻到头、其它平台还能继续 ——
> 这种情况下仍然可以继续翻，直到**所有**平台都没有更多结果。

## 设置页重新整理

设置项越加越多，挤在一条长滚动里很难找。现在：

- 页面**整体加宽**（540 → 900 宽），左右分栏，一眼能看到更多内容；
- 左侧新增**分类标签**，点击切换：
  **播放** / **外观** / **歌词** / **在线播放** / **关于与更新**；
- 「在线播放」标签上带一个数字角标，显示当前已导入的自定义源数量；
- 上次看的是哪一类会被记住，下次打开设置直接停在那里。

> 想换回默认也简单：「关于与更新」→「恢复默认设置」。

## 顺带
