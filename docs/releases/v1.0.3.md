# 提瓦特旋律 v1.0.3

## 检查更新后可以直接下载并安装了

以前点「前往下载」只是用浏览器打开下载页，还得自己找文件、自己点安装。现在：

- 启动时弹出新版本提示 → 点「**下载并安装**」→ 应用自动把更新包下到本地（带进度）→ **自动拉起安装向导**，
  按提示点几下就装完了
- 设置页「关于与更新」里也一样：显示下载进度条，装完直接进入安装向导

**两种分发方式都照顾到了**：

| 你在用 | 下载什么 | 下完之后 |
| --- | --- | --- |
| 安装版 | Setup 安装包 | 直接拉起安装向导 |
| 免安装版 | zip 压缩包 | 在资源管理器里定位，自行解压替换（免安装版不适合自动装，会多出一份） |

> 安装向导会提示关闭本程序，属正常现象。

## 设置页排版整理

- **分组之间加了分隔线**，每个标题前有一道主题色装饰条 —— 七组设置叠在一起时更容易扫读
- 「关于与更新」不再出现「检查更新 [检查更新]」这种重复标签；版本号右对齐、数字等宽
- 按钮统一成同一套样式；虚线框只保留给「上传字体文件」这种真正的文件选择

## 播不了的平台会提前提示

如果某个平台你的源**声明支持但实际播不了**（例如某些源不支持网易云），
现在会在搜索页的平台筛选条上打 ⚠，鼠标悬停可看到具体原因 —— 不必再点进去才发现。

记录会在你成功播放该平台、或改动自定义源之后自动清除。
