# 提瓦特旋律 v1.0.2

## 修复：酷我来源的在线歌曲全部无法播放

v1.0.1 里从「酷我」搜到的歌点击播放会失败，提示类似：

```
在线播放失败：音质降级全部失败 → 独家音源: unknow error
```

**根因**：自定义源脚本读的是 `musicInfo.songmid`，而我们的酷我搜索只提供了 `rid`。
源拿不到 ID 就发了一个残缺请求，后端回了句笼统的错误。逐个字段比对后确认：
`rid` / `id` / `musicId` / `DC_TARGETID` / `MUSICRID` 都不行，`songmid` 和 `hash` 可以。

现在会把平台 ID 同时以 `songmid` / `hash` / `rid` / `id` / `mid` 等常见字段名一并传给源脚本，
兼容不同源的取值习惯。实测从酷我搜到的歌已可正常播放。

**顺带改进的错误提示**：以前失败会把 4 档音质的同一句错误重复 4 遍，刷屏又看不出重点；
现在同一原因只报一次，并附一句提示（多半是该源不支持这个平台，可换其他平台的搜索结果）。

> **说明**：网易云（`wy`）来源对当前这个源仍然失败 —— 试过所有字段名组合都不行，
> 属于**源自身不支持**，不是应用的问题。请优先用酷狗 / QQ 音乐 / 酷我 的搜索结果。
