# 提瓦特旋律 v1.0.7

## 数据回到软件目录（跟 EXE 同级）

按你的要求，**安装版的数据也放回安装目录里，与 `TeyvatMelody.exe` 同级**。
现在两种分发方式的规则完全一致，整个目录自包含 —— 可以整体复制、搬移到别的电脑继续用。

```
TeyvatMelody/           ← 你的安装目录
├─ TeyvatMelody.exe
├─ data/                曲库数据库（歌曲、歌单、收藏、播放历史）
├─ music/               扫描入库的音乐副本；在线下载的歌
├─ cache/               在线播放的音频与歌词缓存
├─ .appdata/            设置、桌面歌词位置、播放进度
├─ sources/             你导入的自定义源脚本
└─ ...
```

「设置 → 关于与更新」里仍会显示数据目录，并可一键打开。

### 但升级**依然不会丢数据**

这一点必须说清楚，因为「数据放在安装目录里」正是之前丢数据的原因：

安装器在升级时会**先执行旧版的卸载程序**，而它默认会 `RMDir /r $INSTDIR` ——
把安装目录整个删掉。所以这一版不是简单地把路径改回去，而是**改了卸载程序的行为**：
electron-builder 提供了 `customRemoveFiles` 宏，可以用它接管「删哪些文件」，
于是现在的规则变成：

| 场景 | 行为 |
| --- | --- |
| **升级**（装新版本覆盖） | 只删应用自己的文件（exe/dll/pak/locales/resources…），**数据目录原样保留** |
| **卸载**（从「应用和功能」里卸载） | 连数据一起删掉，不留残留 |

> ⚠️ **因此：卸载前请先备份。** 把 `data` / `music` / `sources` / `.appdata`
> 复制到别处即可；或者改用免安装版（删文件夹即卸载，数据想留就留着）。
> 随包附带的 `README.txt` 里也写明了这一点。

从 v1.0.6 升上来的话，启动时会自动把 `%LOCALAPPDATA%\TeyvatMelody` 里的数据搬回软件目录，
不用你手动操作。

## 其它

- 修复：同一首歌连点两下「下载」会落出两份重复文件
- 修复：下载进度记录在内存里无限增长
- 修复：酷我来源的歌手名会把 `&` 显示成 `\u0026`
- 修复：歌单里的在线歌曲会被当成本地文件去读，导致播不出声
- 修复：设置页缓存占用显示不变化；小体积改按 KB 显示
- 改进：所有弹窗支持按 **Esc** 关闭
- 修复：同时开两个实例（便携版 + 安装版）会让数据写错目录 —— 后端端口改为动态选定
