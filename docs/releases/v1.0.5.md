# 提瓦特旋律 v1.0.5

## 在线歌曲，现在和本地歌一样好用

以前在线搜到的歌只能「播 / 下一首 / 加队列」—— 收藏不了、进不了歌单、下载不了，
换音质也无从下手。这一版把这些都补上了。

### 收藏 · 加入歌单

在线歌曲现在可以像本地歌一样**收藏**和**加入歌单**，也会进入**最近播放**与**播放统计**。

- 右键任意在线歌曲 → 「收藏」「加入歌单」
- 搜索结果行上直接点 ♡ 也能收藏
- 收藏 / 歌单 / 最近播放里，在线条目会带一个「在线搜索」小标签，一眼可辨

> 实现上，在线歌曲会在曲库里登记一条记录（记住来源平台、平台 ID 与完整的请求信息），
> 所以收藏与歌单用的是**和本地歌同一套机制** —— 不会出现「收藏了两份、状态还不同步」的情况。

### 下载到本地

右键在线歌曲 → 「下载到本地」，按你选的音质把音频真正存进 `music/` 目录，
并**自动登记进音乐库**：

- 封面会存下来**并嵌进文件**，歌词会写成同名 `.lrc`，歌名歌手也会写回文件标签 ——
  文件拿到别的播放器里打开，信息是完整的
- 重名不覆盖，自动加序号
- 如果这首歌刚播过、字节已在本地缓存里，下载会**直接复制**，秒完成
- 下载中会显示进度百分比（无损一首动辄 50 MB，没有进度条实在难熬）
- 已下载过的歌，搜索结果里会标上「已下载」，不会重复下

### 音质切换

- 播放器底栏会显示**当前实际命中的音质**（音质降级后的真实结果）
- 点它，或在右键菜单里选，即可切换音质
- 切换后**从当前位置继续播**，不会跳回开头；暂停中切音质也不会自己放起来
- 音质选项来自你的源脚本声明（自动 / 128K / 320K / FLAC / FLAC 24bit…）

### 歌词也会缓存了

以前每次切到同一首歌都要重新请求一次平台歌词接口（酷狗还要走两步）。
现在歌词会缓存在 `cache/lyrics/` 下，7 天有效，过期自动清理。

设置页的「在线播放缓存」里，占用统计现在会分别列出：

- **音频缓存**（容量上限只管它）
- **歌词缓存**（单独显示份数与体积）

「清空缓存」会把两者一起清掉。数字在设置页打开期间会每 2 秒刷新一次，
边播边看着它涨 —— 不会再出现「明明在播，数字却纹丝不动」的困惑。

## 其它

- 修复：设置页缓存占用显示不变化（进行中的分片现在也计入统计）
- 修复：收藏 / 歌单里的在线歌曲在「最近播放」与启动恢复队列时会被静默丢掉
