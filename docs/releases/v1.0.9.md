# v1.0.9

这一版围绕**在线歌曲与本地曲库的打通**、以及设置页与列表的观感做了集中改进。

## 全部音乐现在包含在线歌曲

以前「全部音乐」只列本地曲库，你收藏或下载过的在线歌不会出现在这里，
容易以为歌丢了。现在它会列出**本地 + 已入库的在线歌曲**：

- 新增**「来源」列**：本地歌显示「本地」，在线歌显示平台名（酷我 / 酷狗 / QQ音乐 / 网易云）
- 新增**来源筛选**：`全部` / `仅本地` / `仅在线`，按钮上直接标出各档数量
- 排序上**本地在前、在线在后** —— 本地歌一定播得出来，先点到的失败概率最低

## 在线搜索：平台选择不再被重置

此前在「在线搜索」里取消勾选某个平台，切到别的页面再回来就会被恢复成全选，
等于选不动。现在：

- 平台勾选会**持久化**，重启软件后依然保留
- 只勾一个平台时，搜索**只查那个平台**（不再偷偷带上其它平台）
- 如果某个平台因为源的问题暂时用不了，会从勾选里自动剔除，而不是留着一个选不中又搜不到的空位

## 设置页与列表的观感

- **设置页各分类高度统一**：以前切标签时弹窗会随内容长短忽大忽小，现在固定尺寸，
  内容多的分类（如「播放」）内部滚动
- **音质列更好读**：以前显示成 `MP3 : 128000k · 44.1kHz` 这种技术参数，列被撑满还没法比较；
  现在只显示关键的一档（`128K` / `320K` / `FLAC`），完整参数移到鼠标悬浮提示
- 收藏 / 歌单里的在线歌标记从「在线搜索」改成**具体平台名**，与「来源」列口径一致
- 设置页「切歌淡入淡出」的开关与滑块不再显示重复文案；滚动条不再露出浅色轨道

## 其它

- 在线搜索结果切页面回来时，滚动位置只在**同一批结果**内还原
  （以前会把上一批的滚动位置套到新搜索上，导致一进来就停在列表底部）

---

## 升级提示

- **数据不会丢**：安装版升级时你的曲库、歌单、收藏、缓存都会保留。
- **卸载会连同数据一起删除**，卸载前请先备份 `data/` `music/` `cache/` `sources/` 这几个目录。
- 免安装版（zip）直接解压覆盖即可，整个目录自包含、可搬移。
