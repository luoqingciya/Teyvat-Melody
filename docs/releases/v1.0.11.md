# v1.0.11

这一版修了你反馈的三处问题，其中**更新时不再需要手动关软件**是最实质的一个。

## 点「下载并安装」后，软件会自己关掉了

以前从旧版升级时，点了「下载并安装」，软件拉起安装程序后**自己还开着**。
而安装程序要替换掉正在运行的程序文件，结果就是卡住、或者弹窗让你手动关闭本程序，
很容易以为更新坏了。

现在：安装向导一起，软件会**自动关闭**（先给你一句提示，再退），
直接按安装向导的提示点下去就行。

顺带明确一下免安装版的行为：免安装版下载的是压缩包，只会**在资源管理器里帮你定位到那个文件**，
软件**不会关闭**，你自己解压覆盖即可。

## 沉浸播放页时间前面那个多余的点

全屏播放时，时间前面出现过一个孤零零的分隔点（像 `· / 03:30`）——
原因是在线歌曲没有本地的编码信息，那个点却照旧画了出来。现在没有音质信息时它不再出现。

## 右键菜单的音质选项不再挤

之前右键在线歌曲时，「音质」下面的选项（自动 / 128K / 320K / FLAC …）
长短不一、换行后挤成一团。现在改成**等宽对齐**，不管几档都排得整整齐齐。

---

## 升级提示

- **数据不会丢**：安装版升级时你的曲库、歌单、收藏、缓存都会保留。
- **卸载会连同数据一起删除**，卸载前请先备份 `data/` `music/` `cache/` `sources/` 这几个目录。
- 免安装版（zip）直接解压覆盖即可，整个目录自包含、可搬移。
