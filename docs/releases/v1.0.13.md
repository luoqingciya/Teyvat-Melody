# v1.0.13

这一版新增**网络设置（HTTP 代理）**，并修掉设置页里一处对不齐的排版。

## 新增：设置页「网络设置」——给在线播放配代理

在线播放要连各平台的接口和音频 CDN。如果你所在网络需要走代理才能访问这些站点，
以前只能干看着，现在可以在 **设置 → 网络设置** 里填：

- 一个「启用」开关
- 代理主机（如 `127.0.0.1`）与端口（如 `7890`）

旁边有「测试连接」可以先试一下通不通，再决定要不要保存。

**代理对以下功能全部生效**（不是只管一部分）：

- 在线搜索（四个平台）
- 音频地址解析与播放（含自定义源脚本发出的请求）
- 歌词、封面
- 下载到本地
- **检查更新**（走代理才能拿到新版本时，这条尤其重要）

几个说明：

- **本机地址永远不走代理。** 软件内部（界面 ↔ 后台）全靠 `127.0.0.1` 通信，
  这部分被塞进代理会导致整个软件连不上自己，所以它被刻意排除在外 —— 你不需要为此做任何事。
- 填了但**没勾启用**时，只要填的内容有误（比如端口不是数字）就会被拦下并提示。
  这是故意的：否则配置会存成空的，而输入框里还留着你的字，
  下次你一勾「启用」就以为生效了，实际是空配置。
- 设置存在软件目录下的 `cache/config.json`，与其它配置一起，升级不会丢。

## 修复：设置页左侧分类「在线播放」和其他项对不齐

「在线播放」后面带一个源数量的角标，把文字挤到换行，比别的分类高出一截。
现在角标不再挤压文字，六个分类高度一致。

## 修复：界面上「收藏」的自动化验证不可靠（仅影响开发）

自动化界面测试里，判断「点了收藏后是哪首歌变了」原先靠**标题比对**。
曲库里存在多首标题互相包含的歌（如「晴天」和「晴天 (KTV版伴奏)」），
比对会认错歌，导致测试**偶发误报**——功能其实是好的。

现在改成看「收藏集合的变化」：点一次只可能影响一首，被改的那首就是答案，与标题无关。
顺带修正了「收藏状态被切换」这条断言的方向判断。**软件功能本身没有任何变化。**

## 升级提示

- **数据不会丢**：安装版升级时你的曲库、歌单、收藏、缓存、代理设置都会保留。
- **卸载会连同数据一起删除**，卸载前请先备份 `data/` `music/` `cache/` `sources/` 这几个目录。
- 免安装版（zip）直接解压覆盖即可；免安装版更新时**不会**自动关闭软件，
  而是下载完在资源管理器里帮你定位到压缩包。

> v1.0.12 修的那条「点『下载并安装』后软件会自己关掉」，如果你还没验证过，
> 这一版依然包含该修复。
