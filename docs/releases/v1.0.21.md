# v1.0.21

新增**可自定义的快捷键**，分「软件内」与「全局」两组。

## 设置 → 快捷键

**软件内快捷键**（程序窗口处于焦点时生效）

| 动作 | 默认 |
|---|---|
| 播放/暂停 | Ctrl + F5 |
| 上一首 / 下一首 | Ctrl + ← / Ctrl + → |
| 快退 5 秒 / 快进 5 秒 | 未设置 |
| 聚焦搜索框 | F1 |
| 最小化程序 / 退出程序 | 未设置 |

**全局快捷键**（窗口最小化或隐藏到托盘后依然生效）

播放/暂停、上一首、下一首、快退/快进 5 秒、增加/减少音量、静音切换、
收藏歌曲、取消收藏、开/关桌面歌词、桌面歌词锁定切换、桌面歌词置顶切换、
最小化程序、显示/隐藏程序、退出程序。

默认：播放/暂停 `Ctrl + Alt + F5`，上一首/下一首 `Ctrl + Alt + ← / →`，
音量 `Ctrl + Alt + ↑ / ↓`，桌面歌词相关 `Ctrl + Alt + 0 / - / =`。
其余留空，需要时自己录。

## 怎么改键

点动作右侧的按键框 → 变成「请按快捷键…」→ **直接按下你想要的组合**即可。
按 `Esc` 可以取消。已经绑定的键右边有个 `✕`，点一下清除。

## 几点说明

- **需要先勾「启用」**。两组各有一个开关，默认都关着（和之前的行为一致，不会突然多出一堆按键拦截）。
- **会被占用的组合会明确告诉你**。全局快捷键是系统级注册，如果某个组合已被别的程序占用，
  就注册不上 —— 界面会直接提示有几个没注册上，而不是让你按了没反应还以为坏了。
  > 顺带一提：`Ctrl + Alt + 方向键` 在 Windows 上经常被 **Intel 显卡的「屏幕旋转」**占着，
  > 撞上它时界面会直接把这一点点出来。
- **只按字母/数字、不带修饰键**的组合不能绑定 —— 那种组合会把正常打字全吃掉。
- 之前那个笼统的「系统全局快捷键」开关移到了新页面里，媒体键（键盘上的播放/暂停、上一首、下一首）
  仍然始终可用。

## 新增：桌面歌词「锁定」与「置顶」

这两个是全局快捷键用到的动作，也一并做出来了：

- **锁定**：歌词条鼠标穿透，压在别的窗口上也不会挡住点击（相当于锁住不让拖）。
- **置顶**：默认开（歌词本来就该浮在最上面），可以关掉。

## 升级提示

- **数据不会丢**：安装版升级时曲库、歌单、收藏、缓存、代理设置都会保留。
- **卸载会连同数据一起删除**，卸载前请先备份 `data/` `music/` `cache/` `sources/` 这几个目录。
- 免安装版（zip）直接解压覆盖即可。

> 如果你还在 v1.0.17 之前，请**手动下载安装包**升级一次 ——
> 那些版本的「下载并安装」是坏的，修不了自己。
