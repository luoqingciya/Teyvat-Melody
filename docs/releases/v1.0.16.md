# v1.0.16

这一版补了**播放设置**里几项常用的能力。

## 新增：任务栏显示播放进度

播放时，任务栏图标上会出现一条进度条；暂停时会变成「暂停」外观，停止后自动消失。

> 设置 → 播放 → **在任务栏上显示当前歌曲播放进度**（默认开）

## 新增：播放歌曲时阻止电脑休眠

听歌时不让系统进入睡眠，避免放到一半被掐断。

> 设置 → 播放 → **播放歌曲时阻止电脑休眠**（默认开）

注意：它**只阻止系统睡眠，不阻止屏幕熄灭** —— 屏幕该黑还是照黑，只是系统不会睡过去。

## 新增：播放出错时自动切换歌曲

以前这条是**真的没有**：在线歌曲解析地址失败时会有提示并换源重试，
但「地址拿到了却拉不到流」「本地文件损坏或被删」「代理中途断了」这几种情况一直没人管，
表现就是**没有声音也不切歌**，只能自己手动点下一首。

现在会捕获播放错误并自动切下一首，同时提示是哪首歌失败了。

> 设置 → 播放 → **播放错误时自动切换歌曲**（默认开）

安全阀：**连续 3 首都失败就停止自动切歌**并提示一次。
否则整个音乐目录被移走、或代理挂掉时，会在几秒内把队列跑完还刷满一屏提示。

## 新增：逐字歌词（主界面与全屏）

桌面歌词早就有逐字高亮了，主界面和全屏播放页只有整行高亮 —— 现在也能逐字。
唱到的字从左往右渐变，未唱到的字保持暗色。

> 设置 → 歌词 → **逐字歌词（主界面/全屏）**

需要有**逐字时间轴**的歌词（多数在线歌词有，本地 `.lrc` 通常只有行级时间轴）。
没有逐字时间轴时自动退回原来的整行高亮，不会变难看。

## 新增：优先播放的音质

在线歌曲播放时可以指定优先尝试哪些音质。

> 设置 → 播放 → **优先播放的音质**

勾选的会优先尝试（由高到低）。**未勾选的不会因此播不出来** ——
它们仍会排在后面兜底，因为一个偏好设置不该把播放本身弄挂。

## 新增：记住播放进度（可关闭）

按歌记忆播放位置、下次从断点续播，这个能力本来就有，但**一直是常开的**。
现在可以关掉。

> 设置 → 播放 → **记住播放进度（下次从断点续播）**（默认开）

## 这一版没有做的（以及为什么）

- **使用设备能处理的最大声道数输出音频** —— 曲库基本是立体声，升混不会多出内容，
  而且多数设备上系统报告的最大声道数就是 2，实际等于没效果，收益存疑。
- **歌词罗马音** —— 假名可以本地转换，但汉字读音需要词典，体积和复杂度都上一个台阶。
- **歌词转繁体** —— 与项目的「零运行时依赖」冲突：简繁表体积可观，
  而且「一简对多繁」（发→發/髮）需要词组判断，纯字符替换会出错。
- **音频输出设备选择 / 设备变更时暂停** —— 技术上可行，但我们的播放链路始终经过 Web Audio，
  切换设备要用 `AudioContext.setSinkId()` 而不是给 `<audio>` 设置（后者会被静默忽略），
  需要真机逐个验证，留到后续。
- **点击与播放列表相同的列表切歌时清空已播放列表** —— 这条的语义还需要先确认。

## 升级提示

- **数据不会丢**：安装版升级时曲库、歌单、收藏、缓存、代理设置都会保留。
- **卸载会连同数据一起删除**，卸载前请先备份 `data/` `music/` `cache/` `sources/` 这几个目录。
- 免安装版（zip）直接解压覆盖即可。
