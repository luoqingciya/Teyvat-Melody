# 提瓦特旋律 v1.0.0

原神主题风格的音乐播放器桌面应用：**本地音乐库 + 洛雪自定义源在线播放**。
基于 Electron + Python (Flask) + Vue 3 混合架构。

---

## 下载

| 版本 | 文件 | 说明 |
| --- | --- | --- |
| **安装版**（推荐） | `TeyvatMelody-Setup-1.0.0.exe` | NSIS 安装程序，可自定义安装目录，自动创建开始菜单与桌面快捷方式 |
| **免安装版** | `TeyvatMelody-1.0.0-x64.zip` | 解压即用，无需安装 |

两者都是**自包含**的：音乐库副本、数据库、设置等运行数据都保存在应用根目录，
因此整个文件夹可以随意搬移或放进 U 盘，换台电脑解压就能继续用。

## 系统要求

- Windows 10 / 11（x64）
- 免安装版无需额外依赖 —— 后端服务已打包为独立 exe 随应用分发

## 功能亮点

### 本地音乐库

- 选择目录扫描入库，自动解析采样率 / 码率 / 声道并展示「音质」列
- HTTP Range 流式播放，进度条可拖动
- 专辑封面、LRC 歌词随播放滚动并高亮当前句
- 收藏夹、多歌单管理、最近播放、播放统计、重复歌曲检测
- 按歌名 / 艺术家 / 专辑实时搜索过滤
- 全屏播放：旋转封面 + 滚动歌词
- 三主题切换（蒙德 / 璃月 / 稻妻）、毛玻璃开关、自定义主色与界面字体

### 在线播放（自定义源）

- 兼容**洛雪音乐自定义源脚本**，在 Node `vm` 沙箱中隔离运行
- 内置 QQ 音乐 / 酷狗 / 网易云 / 酷我 四平台搜索
- **音质降级链**（`flac24bit → flac → 320k → 128k`）+ 多源自动换源，失败时给出明确原因
- 在线歌词自动合并翻译（双语）；酷狗 KRC 解密后支持**逐字卡拉OK**
- 在线封面经同源代理加载，加载失败回退默认封面

### 桌面集成

- **桌面歌词**：透明窗口、逐字卡拉OK、可锁定位置、字号与配色可调
- **迷你播放器小窗**：置顶显示封面 / 标题 / 进度，可遥控播放
- 系统托盘常驻、单实例运行、全局媒体键、切歌通知
- 图形均衡器与音效预设、0.5x–2x 播放速度、睡眠定时、自动跳过静音
- 中文 / English 界面一键切换

## ⚠️ 关于在线播放

**应用不内置任何音乐源。**

在线播放需要你自行导入洛雪格式的自定义源脚本（`.js`），并在「设置 → 自定义源」中导入、启用。
源为**第三方代码**，可发起任意网络请求，请确认可信后再导入；源失效时应用会给出具体原因，
不会静默失败。

## 已知限制

- 仅发布 Windows x64
- 未做代码签名，首次运行 Windows SmartScreen 可能提示，选择「仍要运行」即可
- 在线播放能力取决于第三方源的可用性
- 在线歌曲暂不支持收藏、查看详情等仅对本地文件有意义的功能
