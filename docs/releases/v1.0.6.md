# 提瓦特旋律 v1.0.6

## ⚠️ 升级前请先备份（只这一次）

**这次从 v1.0.5 升到 v1.0.6，请先手动备份数据。** 原因是：

删数据的是**旧版（v1.0.5）的卸载程序**，而它已经在你的电脑上了、我改不了 ——
升级时安装程序会先跑它，它会把安装目录整个删掉。所以这一次升级仍会丢数据。

**备份方法**：打开你的安装目录（例如 `D:\Apps\...\TeyvatMelody`），把这几个文件夹复制到别处：

```
data      曲库数据库（歌曲、歌单、收藏、播放历史）
music     扫描入库的音乐副本 + 在线下载的歌
sources   你导入的自定义源脚本
.appdata  设置、音量、主题、播放进度
cache     在线播放缓存（可以不备份，删了只是下次重新联网）
```

**升级完成后**，把这些文件夹放到新的数据目录里即可（路径见下）。新版会自动识别。

> **从 v1.0.6 开始，以后升级不再需要任何备份。** 这就是本版修复的问题。

## 修复：更新会丢失全部数据

这是本版最重要的修复，也是你反馈的问题。

**根因**：安装版升级时，安装程序会先执行旧版的卸载程序，而卸载程序会执行
`RMDir /r $INSTDIR` —— **把安装目录整个删掉**。而这个应用此前把数据
（`data/` `music/` `sources/` `.appdata/` `cache/`）全都放在安装目录里。
于是「更新」= 删掉旧版（连数据一起）+ 装新版 → 每次更新数据全丢。

**修复**：安装版的数据改放到**安装目录之外**：

| 分发方式 | 数据位置 | 为什么 |
| --- | --- | --- |
| **安装版** | `%LOCALAPPDATA%\TeyvatMelody` | 升级/卸载都不会碰它 |
| **免安装版** | 软件目录（同以前） | 整个文件夹仍可随意搬移 —— 免安装版的立足点 |

（`%LOCALAPPDATA%` 一般是 `C:\Users\你的用户名\AppData\Local`，
在资源管理器地址栏粘贴这一行即可打开。）

**旧数据自动搬家**：如果检测到安装目录里还有老版本的数据、而新位置是空的，
启动时会自动搬过去（跨盘符也能处理）。

**设置页现在会显示数据目录**，还有一个「打开数据目录」按钮 —— 你的数据到底在哪，
自己随时能确认，不用再猜。

## 修复：同时开两个实例会让数据写错地方

后端此前固定监听 `5000` 端口。如果你同时开着两个副本（例如一个免安装版 + 一个安装版），
后启动的那个抢不到端口，它的窗口就会连到**先启动那个实例的后端** ——
于是你在这个窗口里的操作，数据被写进了**另一个副本的数据目录**。
表现就是「数据莫名错乱/丢失」。

现在后端端口在启动时**动态选定**，两个实例互不干扰。
