# v1.0.25

## 修复：托盘创建失败会导致程序完全无法启动

如果系统托盘当前不可用（比如 `explorer.exe` 崩过或正在重启），程序在**启动阶段就会直接失败** ——
双击图标毫无反应，没有窗口、也没有任何提示，看起来像是「打不开」。

现在这种情况会**降级为无托盘运行**：窗口、播放、后台服务全都照常，只是少了托盘那个入口，
并且会在日志里记一笔。

> 这类「启动就静默失败」的问题最难受 —— 用户连界面都看不到，更没法告诉我们出了什么事。
> 宁可少一个托盘图标，也不能让整个程序起不来。

## 升级提示

- **数据不会丢**：安装版升级时曲库、歌单、收藏、缓存、代理设置都会保留。
- **卸载会连同数据一起删除**，卸载前请先在「设置 → 关于与更新」里导出一份备份。
- 免安装版（zip）直接解压覆盖即可。

> 如果你还在 v1.0.17 之前，请**手动下载安装包**升级一次 ——
> 那些版本的「下载并安装」是坏的，修不了自己。
