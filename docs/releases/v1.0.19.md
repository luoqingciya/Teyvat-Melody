# v1.0.19

修两个问题：**歌词字号调大后被裁**、**设置每次重启都重置**。

## 修复：全屏歌词字号调大后，文字被上下裁掉

行高原本是**写死的 46px**，而字号是可调的（12–32px）。字号一大，内容就比行还高，上下各切掉一截。

实测：

| 歌词字号 | 内容实际高度 | 行高（旧） |
|---|---|---|
| 16px | 46px | 46px ← 刚好 |
| 24px | 70px | 46px ← **被裁** |
| 32px | 93px | 46px ← **被裁** |

现在行高会跟着字号一起变（16px 字号 → 50px 行高，32px → 98px），文字不再被裁。

顺带修好一个一直存在的小问题：**翻译行以前会被压扁**（12px 被挤到 7px），
现在它也跟着字号缩放，比例正常。

## 修复：设置每次重启都重置（不只是升级后）

这个问题的根子比较绕：界面是从 `http://127.0.0.1:<端口>` 加载的，
而浏览器把网页存储（localStorage）**按「来源」隔离，来源里包含端口号**。

原来的端口是每次启动**让系统随便给一个**（实测三次分别是 53375 / 53414 / 53446），
于是每次启动都换了一个「来源」——你的设置其实**还写在磁盘上**，只是挂在另一个来源下，
界面上看起来就是「全被重置了」。

因为程序常驻托盘、平时很少重启，所以这个问题主要是在**升级后**被察觉到的。

现在端口改成**按软件数据目录算出来的固定值**：同一个安装每次启动端口都一样，设置就能留住了。
同时保留了原本的设计意图 —— **便携版和安装版各用各的端口，不会互相串数据**。

> ⚠️ 之前被「重置」掉的设置找不回来了（它们散落在各个旧端口对应的存储里）。
> 这一版开始设置的改动会正常保留。

## 升级提示

- **数据不会丢**：安装版升级时曲库、歌单、收藏、缓存、代理设置都会保留。
- **卸载会连同数据一起删除**，卸载前请先备份 `data/` `music/` `cache/` `sources/` 这几个目录。
- 免安装版（zip）直接解压覆盖即可。

> 如果你还在 v1.0.17 之前，请**手动下载安装包**升级一次 ——
> 那些版本的「下载并安装」是坏的，修不了自己。
