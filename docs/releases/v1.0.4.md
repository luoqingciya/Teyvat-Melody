# 提瓦特旋律 v1.0.4

## 在线歌曲现在会缓存在本地

以前每播一次在线歌曲都要**从 CDN 完整重新拉一遍**；拖动进度条也是重新联网取流。现在：

- **听过的歌会缓存在本地**，再播直接从硬盘读 —— 秒开，不耗流量
- **拖动进度条走本地文件**，不再重新联网
- 缓存位置：软件根目录 `cache/`，可随时清空

设置页新增「**在线播放缓存**」分组：

| 项 | 说明 |
| --- | --- |
| 启用缓存 | 关掉就回到「每次都联网取」的行为 |
| 容量上限 | 256 MB / 512 MB / 1 GB（默认）/ 2 GB，超出后自动淘汰最久未用的 |
| 已用 | 当前占用，旁边可一键清空 |

**两个细节**：

- 只有**完整下载下来**的音频才会入缓存，绝不会把「半首歌」当成完整缓存
- 你**中途切歌或拖动进度条**时，已经下载的部分不会被浪费 —— 会在后台把剩下的读完再存下来，
  而且**不会额外多耗流量**（复用同一条连接）。
  但如果你只是点一下立刻切走，则不会替你在后台偷偷下载整首歌。

> 说明：为什么不是浏览器缓存 —— 音乐 CDN 的地址带时效签名、每次播放都不同，
> 拿它当缓存键永远命不中。所以这里用的是「平台 + 歌曲ID + 音质」这样的稳定标识。
