## 本次更新

### 修复

- **在线搜索报「An object could not be cloned.」** —— 根因是传给主进程的平台列表是 Vue 的响应式数组，
  跨进程边界时无法被复制。已在调用侧改为传普通值，现在搜索可正常返回结果
  （实测四平台共 120 条结果）

### 新增

- **内置更新检查** —— 启动后静默检查 GitHub Release，发现新版本会弹出提示，点「前往下载」即打开下载页；
  也可以在「设置 → 关于与更新」里手动检查、查看更新说明、或忽略某个版本

### 说明：为什么是「提示下载」而不是「自动安装」

自动下载安装需要 `electron-updater`，它有三个现实问题：

1. **只支持安装版** —— 免安装 zip 没有安装位置，无法自更新
2. **未签名的更新包会被 Windows SmartScreen 拦截** —— 静默安装体验反而更差
3. 需要引入额外的运行时依赖

所以这里做的是「查 → 告知 → 跳转下载」，安装版与免安装版行为一致，也不需要额外依赖。
将来若做了代码签名，可以再考虑升级为静默更新。
