# v1.0.22

## 修复：「快捷键」分类没有图标

上一版新增的「快捷键」设置页，其他分类都有图标，只有它没有 —— 因为图标名写错了
（写的是一个图标集里不存在的名字，而查不到时会**静默渲染成空白**，不报错也不警告）。

现在补上了一个键盘图标。顺手加了一条自检：**设置页每个分类的图标名都必须在图标集里存在**，
以后再写错会直接测试失败，而不是安静地少一个图标。

## 升级提示

- **数据不会丢**：安装版升级时曲库、歌单、收藏、缓存、代理设置都会保留。
- **卸载会连同数据一起删除**，卸载前请先备份 `data/` `music/` `cache/` `sources/` 这几个目录。
- 免安装版（zip）直接解压覆盖即可。

> 如果你还在 v1.0.17 之前，请**手动下载安装包**升级一次 ——
> 那些版本的「下载并安装」是坏的，修不了自己。
