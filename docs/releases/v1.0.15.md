## 「测试连接」失败时会告诉你到底是哪里填错了

v1.0.13 加了网络设置（HTTP 代理）。如果端口填错，之前只会显示一行

> 代理拒绝隧道（HTTP/1.1 405 Method Not Allowed）

这句话对着手排查没有任何帮助 —— 你根本不知道要改什么。

现在会直接点出最可能的原因。**最常见的填错方式是把代理软件的「控制接口」当成了代理端口**：
Clash / mihomo 的控制接口（external-controller）默认就在 **9090**，它只接受 GET 请求，
收到代理请求就回 405；而真正的代理端口是 **mixed-port，默认 7890**。

现在这种情况会提示：

> 代理拒绝隧道（HTTP/1.1 405 Method Not Allowed）：该端口只接受 GET，
> 看起来是代理软件的「控制接口」而不是代理端口（Clash / mihomo 的控制接口默认 9090；
> 代理端口是 mixed-port，默认 7890），请改填代理端口

另外两种情况也补了提示：

- 代理要求认证（407）→ 说明本软件暂不支持带用户名密码的代理；
- 该端口不是 HTTP 代理 / 不支持 CONNECT 隧道（400、501）。

---

## 怎么确认自己该填哪个端口

- **Clash / mihomo**：看配置里的 `mixed-port`（默认 **7890**）。控制接口是
  `external-controller`（默认 9090），**那个不能填**。
- **v2rayN / Xray**：看「本地监听端口」，通常是 **10809**（HTTP）。
- 拿不准就填 **7890** 试试 —— 如果你用的是 Clash 系的软件，多半就是它。

## 升级提示

- **数据不会丢**：安装版升级时曲库、歌单、收藏、缓存、代理设置都会保留。
- **卸载会连同数据一起删除**，卸载前请先备份 `data/` `music/` `cache/` `sources/` 这几个目录。
- 免安装版（zip）直接解压覆盖即可。
